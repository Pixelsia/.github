# Pixelsia‌

Pixelsia Minecraft Server

## Pixelsiaとは？

素晴らしいMinecraftサーバーです。（現在開発中）

## 組織図（予定）

```
Pixelsia LLC（設立予定）
├─ MCServer：Clasteria（くらすてりあ）
│  └─ 教育コンテンツ：CodingCraft
└─ ネットワーク：Connectia（こねくてぃあ）
```

## 主要なサービス

### Clasteria（くらすてりあ）

- Minecraftサーバー本体（運営・開発中）
- 教育コンテンツ **CodingCraft** を内包

### CodingCraft（Clasteria内の教育コンテンツ）

- 遊びながら学べるプログラミング／ものづくり系の学習体験

### Connectia（こねくてぃあ）

- Pixelsiaが提供するネットワーク（構想中）


## 理念

**新しい居場所の選択肢**
 
## Vision（目指す姿）

- 世代・地域を越えて人々が集まり、  
- 創造・協働・学びが自然に生まれるデジタルコミュニティを築く。

## Mission（使命）

- 子どもから大人まで楽しめる、安全で快適なオンライン環境を提供する  
- 遊びながら学べるコンテンツやイベントを継続的に創出する  
- クリエイター・教育者・プレイヤーが協力できるプラットフォームを構築する  
- Minecraftサーバー文化の再活性化に貢献する

## Value（大切にする価値観）

- **Experience（体験）**：プレイヤー一人ひとりに特別で忘れられない体験を提供する
- **Creativity（創造性）**：自由な発想と作品づくりを尊重する  
- **Community（コミュニティ）**：誰もが参加しやすい温かい交流の場をつくる  
- **Learning（学び）**：遊びと学びを融合させた新しい教育体験を追求する  
- **Safety（安全性）**：安心して活動できる環境とルールを整える  
- **Innovation（革新）**：常に新しい企画や仕組みでMinecraftの可能性を広げる
